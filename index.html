GERADOR DE CÓDIGO DE BARRAS DUN-14

Aplicativo independente · versão de teste 1.0.1

Criar ou abrir código

O último número é o dígito verificador. O sistema valida o DUN-14 antes de gerar ou salvar.

Se o código sair à esquerda, aumente este valor. O ajuste desloca apenas as barras e os números, sem mudar o tamanho ou a posição das etiquetas.

Pré-visualização

Digite um DUN-14 válido e clique em GERAR / VISUALIZAR.

Confira o código com o leitor antes de produzir grandes quantidades.

Biblioteca de códigos salvos

    Os códigos ficam salvos neste navegador/dispositivo. Exporte um backup para protegê-los ou transferi-los para outro dispositivo. A importação une os registros, sem apagar os existentes.
